# Mi-Hy-Prosthetic-Rhizosphere
Mi-Hy is a circular Hydroponic-Bioelectrical System for urban agriculture that merges Microbial Fuel Cells with hydroponics. Featuring a bioengineered prosthetic rhizosphere, it eliminates synthetic nitrogen use. By valorizing wastewater and CO2, Mi-Hy bioremediates nutrients, fixes carbon, and generates electricity for sustainable plant growth.
